# rim v1 — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Собрать из `rim.toml` детерминированный образ диска `rim.img` (aarch64, UEFI). Образ должен грузиться в QEMU и на Hetzner CAX: свой PID 1, статический userspace, корень erofs только для чтения, ssh по ключу.

**Architecture:** Три Rust-крейта в одном workspace:
- `rim-manifest` — тип и валидация манифеста;
- `rim-init` — PID 1, чистый автомат и тонкий слой эффектов;
- `rim-build` — сборщик: пакеты, корень, UKI, GPT.

`rim-build` работает в Docker-контейнере на Alpine (linux/arm64) и зовёт `mkfs.erofs`, `ukify`, `mtools` и `mke2fs`. GPT пишет сам. Тест загрузки идёт на хосте в QEMU с HVF.

**Tech Stack:** Rust (edition 2024), serde + toml, sha2, crc32fast, nix 0.30, Alpine 3.24, Linux 6.18 LTS, busybox 1.37, dropbear, systemd-stub 257 (`ukify`), erofs-utils, mtools, e2fsprogs, QEMU + edk2.

**Spec:** `docs/superpowers/specs/2026-10-05-rim-v1-design.md`

## Global Constraints

- Целевая архитектура только `aarch64`; Rust-цель в контейнере — штатная Alpine (musl), статика через `RUSTFLAGS="-C target-feature=+crt-static"`.
- Образ контейнера: `alpine:3.24@sha256:294b683cb724975bec92580e1e685676bd4b50bda910ddb8c51d4cabeaec77e6`.
- `SOURCE_DATE_EPOCH = 1767225600` (2026-01-01T00:00:00Z) — единственный источник времени в сборке.
- Манифест: TOML, `deny_unknown_fields` на каждом уровне, без логики.
- Сектор 512 байт, разделы выровнены по 1 MiB (2048 секторов).
- PARTLABEL'ы ровно: `esp`, `root-A`, `root-B`, `data`.
- cmdline ядра: `root=PARTUUID=<root-A> rootfstype=erofs ro rootwait console=ttyAMA0 console=tty0 panic=10`.
- Домашний каталог root — `/data/root`; ключи ssh переписываются из манифеста при каждой загрузке.
- PID 1 не паникует: в рабочем цикле нет `unwrap()`/`expect()`; при ошибке установки — аварийный `/bin/sh` на консоли.
- Сигналы выключения по соглашению busybox: `SIGUSR2` poweroff, `SIGTERM` reboot, `SIGUSR1` halt, `SIGINT` reboot.
- Backoff перезапуска: 1 → 2 → 4 → … → 30 с; сброс до 1 после ≥60 с работы; на выключение 5 с до SIGKILL.
- Строка готовности в консоли — ровно `rim: ready`.
- Никаких loop-устройств и `--privileged` в Docker.
- Отклонения от спеки, принятые в плане:
  - `nix` вместо `rustix`, потому что нужен `signalfd`;
  - конфиг ядра лежит в `pkgs/linux/virt.config`, а не в `kernel/`, чтобы входить в ключ кэша пакета;
  - у таргета поле `kernel = "linux"` (имя пакета) вместо `kernel_config`.

## Review Focus

1. **Манифест без ssh-ключей** → в систему не войти. Ожидание: `rim-build` отказывается собирать с понятной ошибкой. Тест — в Task 1, `rejects_missing_ssh_keys`.
2. **Бинарник сервиса отсутствует или `exec` падает** → init не должен крутиться в горячем цикле и не должен падать. Ожидание: сервис уходит в backoff. Тест — в Task 2, `spawn_failure_goes_to_backoff_without_hot_loop`.
3. **Вторая загрузка** (ключ хоста уже в `/data`) → ключ нельзя перегенерировать, иначе ssh ругается на подмену хоста. Тест — в Task 9: перезагрузка, затем сравнение отпечатка при `StrictHostKeyChecking=yes`.
4. **Образ залит на диск больше себя** (`dd` на диск VPS в 40 ГБ) → резервная GPT не в конце диска. Ожидание: система всё равно грузится. Тест — в Task 9: `truncate -s 2G` перед загрузкой.
5. **Опция ядра молча выпала при `allnoconfig`** (неудовлетворённая зависимость) → ядро без нужного драйвера. Ожидание: сборка падает и называет опцию. Тест — в Task 7, `check-config.sh`.

```rust
//! Манифест rim: данные без логики. Всё, что не описано здесь, — ошибка.

use serde::{Deserialize, Deserializer};
use std::collections::BTreeMap;
use std::fmt;

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct ManifestError(pub String);

impl fmt::Display for ManifestError {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        f.write_str(&self.0)
    }
}

impl std::error::Error for ManifestError {}

#[derive(Debug, Clone, PartialEq, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct Manifest {
    pub system: System,
    #[serde(default)]
    pub service: BTreeMap<String, Service>,
    #[serde(default)]
    pub target: BTreeMap<String, Target>,
}

#[derive(Debug, Clone, PartialEq, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct System {
    pub hostname: String,
    pub packages: Vec<String>,
    #[serde(default)]
    pub ssh_authorized_keys: Vec<String>,
}

#[derive(Debug, Clone, PartialEq, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct Service {
    pub exec: Vec<String>,
    #[serde(default)]
    pub restart: Restart,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Default, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum Restart {
    #[default]
    Always,
    Never,
}

#[derive(Debug, Clone, PartialEq, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct Target {
    pub boot: Boot,
    pub kernel: String,
    pub disk: Disk,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Deserialize)]
pub enum Boot {
    #[serde(rename = "uefi-uki")]
    UefiUki,
}

#[derive(Debug, Clone, PartialEq, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct Disk {
    pub esp: Size,
    pub root: Size,
    pub data: Size,
}

/// Размер в байтах. В манифесте записывается как "128M", "1G", "1024K".
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord)]
pub struct Size(pub u64);

impl Size {
    pub fn parse(s: &str) -> Result<Size, String> {
        let (num, unit) = s.split_at(s.len().saturating_sub(1));
        let mult: u64 = match unit {
            "K" => 1 << 10,
            "M" => 1 << 20,
            "G" => 1 << 30,
            _ => return Err(format!("размер {s:?}: нужен суффикс K, M или G")),
        };
        let n: u64 = num.parse().map_err(|_| format!("размер {s:?}: не число"))?;
        n.checked_mul(mult).map(Size).ok_or_else(|| format!("размер {s:?}: переполнение"))
    }
}

impl<'de> Deserialize<'de> for Size {
    fn deserialize<D: Deserializer<'de>>(d: D) -> Result<Self, D::Error> {
        let s = String::deserialize(d)?;
        Size::parse(&s).map_err(serde::de::Error::custom)
    }
}

const MIB: u64 = 1 << 20;

pub fn parse(text: &str) -> Result<Manifest, ManifestError> {
    let m: Manifest = toml::from_str(text).map_err(|e| ManifestError(e.to_string()))?;
    validate(&m)?;
    Ok(m)
}

fn validate(m: &Manifest) -> Result<(), ManifestError> {
    let err = |s: String| Err(ManifestError(s));
    let h = &m.system.hostname;
    let ok_host = !h.is_empty()
        && h.len() <= 63
        && h.bytes().all(|b| b.is_ascii_lowercase() || b.is_ascii_digit() || b == b'-')
        && !h.starts_with('-');
    if !ok_host {
        return err(format!("system.hostname {h:?}: только a-z, 0-9 и '-', до 63 символов"));
    }
    if m.system.ssh_authorized_keys.is_empty() {
        return err("system.ssh_authorized_keys пуст: без ключа в систему не войти".into());
    }
    for k in &m.system.ssh_authorized_keys {
        if !(k.starts_with("ssh-") || k.starts_with("ecdsa-")) || k.contains('\n') {
            return err(format!("system.ssh_authorized_keys: {k:?} не похож на публичный ключ"));
        }
    }
    for (name, s) in &m.service {
        match s.exec.first() {
            Some(p) if p.starts_with('/') => {}
            _ => return err(format!("service.{name}.exec: нужен абсолютный путь первым элементом")),
        }
    }
    if m.target.is_empty() {
        return err("нет ни одного [target.*]".into());
    }
    for (name, t) in &m.target {
        for (field, size) in [("esp", t.disk.esp), ("root", t.disk.root), ("data", t.disk.data)] {
            if size.0 < MIB || size.0 % MIB != 0 {
                return err(format!("target.{name}.disk.{field}: нужно кратно 1M и не меньше 1M"));
            }
        }
    }
    Ok(())
}
```

```rust
#[cfg(test)]
mod tests {
    use super::*;
    use rim_manifest::Restart;

    fn sup(specs: &[(&str, Restart)]) -> Supervisor {
        Supervisor::new(specs.iter().map(|(n, r)| (n.to_string(), *r)))
    }
    fn spawn(n: &str) -> Action { Action::Spawn { name: n.into() } }
    fn spawned(n: &str, pid: i32, now: u64) -> Event { Event::Spawned { name: n.into(), pid, now } }
    fn exited(pid: i32, now: u64) -> Event { Event::Exited { pid, status: 1, now } }
    fn spawns(a: &[Action]) -> Vec<&Action> { a.iter().filter(|x| matches!(x, Action::Spawn { .. })).collect() }

    #[test]
    fn boot_spawns_all_services_in_name_order() {
        let mut s = sup(&[("sshd", Restart::Always), ("network", Restart::Always)]);
        assert_eq!(s.step(Event::Boot { now: 0 }), vec![spawn("network"), spawn("sshd")]);
    }

    #[test]
    fn ready_emitted_once_after_all_started() {
        let mut s = sup(&[("a", Restart::Always), ("b", Restart::Always)]);
        s.step(Event::Boot { now: 0 });
        assert!(!s.step(spawned("a", 10, 0)).contains(&Action::Ready));
        assert!(s.step(spawned("b", 11, 0)).contains(&Action::Ready));
        s.step(exited(10, 1));
        let again = s.step(Event::Tick { now: 2 });
        let again2 = s.step(spawned("a", 12, 2));
        assert!(!again.contains(&Action::Ready) && !again2.contains(&Action::Ready));
    }

    #[test]
    fn crashed_service_respawns_after_backoff() {
        let mut s = sup(&[("a", Restart::Always)]);
        s.step(Event::Boot { now: 0 });
        s.step(spawned("a", 10, 0));
        s.step(exited(10, 5));
        assert_eq!(s.state("a"), Some(&SvcState::Backoff { until: 6 }));
        assert!(spawns(&s.step(Event::Tick { now: 5 })).is_empty());
        assert_eq!(spawns(&s.step(Event::Tick { now: 6 })), vec![&spawn("a")]);
    }

    #[test]
    fn backoff_doubles_up_to_thirty() {
        let mut s = sup(&[("a", Restart::Always)]);
        s.step(Event::Boot { now: 0 });
        let mut now = 0;
        let mut waits = vec![];
        for pid in 1..=7 {
            s.step(spawned("a", pid, now));
            s.step(exited(pid, now));
            let SvcState::Backoff { until } = *s.state("a").unwrap() else { panic!() };
            waits.push(until - now);
            now = until;
            s.step(Event::Tick { now });
        }
        assert_eq!(waits, vec![1, 2, 4, 8, 16, 30, 30]);
    }

    #[test]
    fn stable_run_resets_backoff() {
        let mut s = sup(&[("a", Restart::Always)]);
        s.step(Event::Boot { now: 0 });
        s.step(spawned("a", 1, 0));
        s.step(exited(1, 0)); // ждём 1
        s.step(Event::Tick { now: 1 });
        s.step(spawned("a", 2, 1));
        s.step(exited(2, 1)); // ждём 2
        s.step(Event::Tick { now: 3 });
        s.step(spawned("a", 3, 3));
        s.step(exited(3, 63)); // проработал 60 с
        assert_eq!(s.state("a"), Some(&SvcState::Backoff { until: 64 }));
    }

    #[test]
    fn never_restart_service_stops() {
        let mut s = sup(&[("once", Restart::Never)]);
        s.step(Event::Boot { now: 0 });
        s.step(spawned("once", 5, 0));
        s.step(exited(5, 1));
```

```rust
//! Логика PID 1 без системных вызовов: событие → новое состояние + действия.

use rim_manifest::Restart;
use std::collections::BTreeMap;

pub const BACKOFF_MIN: u64 = 1;
pub const BACKOFF_MAX: u64 = 30;
pub const STABLE_AFTER: u64 = 60;
pub const GRACE: u64 = 5;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum ShutdownKind { Poweroff, Reboot, Halt }

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Sig { Term, Kill }

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum SvcState {
    Starting,
    Running { pid: i32, since: u64 },
    Backoff { until: u64 },
    Stopped,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Event {
    Boot { now: u64 },
    Spawned { name: String, pid: i32, now: u64 },
    SpawnFailed { name: String, now: u64 },
    Exited { pid: i32, status: i32, now: u64 },
    Tick { now: u64 },
    ShutdownRequested { kind: ShutdownKind, now: u64 },
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Action {
    Spawn { name: String },
    Signal { pid: i32, sig: Sig },
    Log { line: String },
    Ready,
    Finish { kind: ShutdownKind },
}

struct Svc {
    restart: Restart,
    state: SvcState,
    next_delay: u64,
}

struct Shutdown {
    kind: ShutdownKind,
    deadline: u64,
    killed: bool,
    finished: bool,
}

pub struct Supervisor {
    svcs: BTreeMap<String, Svc>,
    ready: bool,
    shutdown: Option<Shutdown>,
}

impl Supervisor {
    pub fn new(specs: impl IntoIterator<Item = (String, Restart)>) -> Self {
        let svcs = specs
            .into_iter()
            .map(|(n, restart)| (n, Svc { restart, state: SvcState::Stopped, next_delay: BACKOFF_MIN }))
            .collect();
        Supervisor { svcs, ready: false, shutdown: None }
    }

    pub fn state(&self, name: &str) -> Option<&SvcState> {
        self.svcs.get(name).map(|s| &s.state)
    }

    pub fn step(&mut self, ev: Event) -> Vec<Action> {
        let mut out = Vec::new();
        match ev {
            Event::Boot { .. } => {
                for (name, svc) in self.svcs.iter_mut() {
                    svc.state = SvcState::Starting;
                    out.push(Action::Spawn { name: name.clone() });
                }
                self.check_ready(&mut out);
            }
            Event::Spawned { name, pid, now } => {
                if let Some(svc) = self.svcs.get_mut(&name) {
                    svc.state = SvcState::Running { pid, since: now };
                    if self.shutdown.is_some() {
                        out.push(Action::Signal { pid, sig: Sig::Term });
                    }
                }
                self.check_ready(&mut out);
            }
            Event::SpawnFailed { name, now } => {
                out.push(Action::Log { line: format!("[{name}] не удалось запустить") });
                if self.shutdown.is_some() {
                    if let Some(svc) = self.svcs.get_mut(&name) {
                        svc.state = SvcState::Stopped;
                    }
                    self.check_finish(&mut out);
                } else {
                    self.schedule_restart(&name, now, 0);
                }
                self.check_ready(&mut out);
            }
            Event::Exited { pid, status, now } => {
                let Some(name) = self.name_by_pid(pid) else { return out };
                out.push(Action::Log { line: format!("[{name}] завершился, статус {status}") });
                if self.shutdown.is_some() {
                    if let Some(svc) = self.svcs.get_mut(&name) {
                        svc.state = SvcState::Stopped;
                    }
                    self.check_finish(&mut out);
                    return out;
                }
                let (restart, since) = match self.svcs.get(&name) {
                    Some(Svc { restart, state: SvcState::Running { since, .. }, .. }) => (*restart, *since),
                    _ => return out,
                };
                match restart {
                    Restart::Never => {
                        if let Some(svc) = self.svcs.get_mut(&name) {
                            svc.state = SvcState::Stopped;
                        }
                    }
                    Restart::Always => self.schedule_restart(&name, now, now.saturating_sub(since)),
                }
            }
            Event::Tick { now } => {
                if let Some(sd) = self.shutdown.as_mut() {
                    if sd.finished {
                        return out;
                    }
                    if !sd.killed && now >= sd.deadline {
                        sd.killed = true;
                        for svc in self.svcs.values() {
                            if let SvcState::Running { pid, .. } = svc.state {
                                out.push(Action::Signal { pid, sig: Sig::Kill });
                            }
                        }
                    } else if sd.killed && now >= sd.deadline + GRACE {
                        sd.finished = true;
                        out.push(Action::Finish { kind: sd.kind });
                    }
                    return out;
                }
                for (name, svc) in self.svcs.iter_mut() {
                    if let SvcState::Backoff { until } = svc.state {
                        if now >= until {
                            svc.state = SvcState::Starting;
                            out.push(Action::Spawn { name: name.clone() });
                        }
                    }
                }
            }
            Event::ShutdownRequested { kind, now } => {
                if self.shutdown.is_some() {
                    return out;
                }
                self.shutdown = Some(Shutdown { kind, deadline: now + GRACE, killed: false, finished: false });
                for svc in self.svcs.values_mut() {
                    match svc.state {
                        SvcState::Running { pid, .. } => out.push(Action::Signal { pid, sig: Sig::Term }),
                        SvcState::Starting => {}
                        _ => svc.state = SvcState::Stopped,
                    }
                }
                self.check_finish(&mut out);
            }
        }
        out
    }

    fn name_by_pid(&self, pid: i32) -> Option<String> {
        self.svcs.iter().find_map(|(n, s)| match s.state {
            SvcState::Running { pid: p, .. } if p == pid => Some(n.clone()),
            _ => None,
        })
    }

    fn schedule_restart(&mut self, name: &str, now: u64, ran: u64) {
        let Some(svc) = self.svcs.get_mut(name) else { return };
        if ran >= STABLE_AFTER {
            svc.next_delay = BACKOFF_MIN;
        }
        svc.state = SvcState::Backoff { until: now + svc.next_delay };
        svc.next_delay = (svc.next_delay * 2).min(BACKOFF_MAX);
    }

    fn check_ready(&mut self, out: &mut Vec<Action>) {
        if !self.ready && self.svcs.values().all(|s| s.state != SvcState::Starting) {
            self.ready = true;
            out.push(Action::Ready);
        }
    }

    fn check_finish(&mut self, out: &mut Vec<Action>) {
        let all_down = self
            .svcs
            .values()
            .all(|s| !matches!(s.state, SvcState::Running { .. } | SvcState::Starting));
        if let Some(sd) = self.shutdown.as_mut() {
            if all_down && !sd.finished {
                sd.finished = true;
                out.push(Action::Finish { kind: sd.kind });
            }
        }
    }
}
```

```rust
    uevents.iter().find_map(|(dev, ue)| {
        ue.lines()
            .any(|l| l.strip_prefix("PARTNAME=") == Some(partname))
            .then(|| format!("/dev/{dev}"))
    })
}

    keys.iter().map(|k| format!("{k}\n")).collect()
```

```rust
//! Всё, что трогает ядро: монтирование, сигналы, процессы, перезагрузка.
//! Логика решений — в core::Supervisor; здесь только перевод событий и действий.

use crate::core::{Action, Event, ShutdownKind, Sig, Supervisor};
use crate::setup;
use nix::mount::{MsFlags, mount, umount};
use nix::poll::{PollFd, PollFlags, PollTimeout, poll};
use nix::sys::reboot::{RebootMode, reboot};
use nix::sys::signal::{SigSet, SigmaskHow, Signal, kill, sigprocmask};
use nix::sys::signalfd::{SfdFlags, SignalFd};
use nix::sys::wait::{WaitPidFlag, WaitStatus, waitpid};
use nix::unistd::{Pid, sethostname, setsid, sync};
use std::fs::{self, File, OpenOptions};
use std::io::{BufRead, BufReader, Read, Write};
use std::os::fd::AsFd;
use std::os::unix::fs::PermissionsExt;
use std::os::unix::process::CommandExt;
use std::process::{Command, Stdio};
use std::sync::{Arc, Mutex};
use std::time::Instant;

const MANIFEST: &str = "/etc/rim/system.toml";

struct Console(Mutex<Vec<File>>);

impl Console {
    fn open() -> Console {
        let active = fs::read_to_string("/sys/class/tty/console/active").unwrap_or_default();
        let files = setup::console_paths(&active)
            .iter()
            .filter_map(|p| OpenOptions::new().write(true).open(p).ok())
            .collect();
        Console(Mutex::new(files))
    }
    fn line(&self, s: &str) {
        if let Ok(mut files) = self.0.lock() {
            for f in files.iter_mut() {
                let _ = writeln!(f, "{s}");
            }
        }
    }
}

pub fn run() -> ! {
    let _ = mount_early();
    let console = Arc::new(Console::open());
    console.line("rim: init");
    match prepare(&console) {
        Ok(manifest) => supervise(manifest, console),
        Err(e) => emergency(&console, &e),
    }
}

fn mount_early() -> nix::Result<()> {
    let nodev = MsFlags::MS_NOSUID | MsFlags::MS_NODEV | MsFlags::MS_NOEXEC;
    mount(Some("proc"), "/proc", Some("proc"), nodev, None::<&str>)?;
    mount(Some("sysfs"), "/sys", Some("sysfs"), nodev, None::<&str>)?;
    mount(Some("devtmpfs"), "/dev", Some("devtmpfs"), MsFlags::MS_NOSUID, Some("mode=0755"))?;
    let _ = fs::create_dir_all("/dev/pts");
    mount(Some("devpts"), "/dev/pts", Some("devpts"), MsFlags::MS_NOSUID | MsFlags::MS_NOEXEC, Some("mode=620,ptmxmode=666"))?;
    mount(Some("tmpfs"), "/run", Some("tmpfs"), MsFlags::MS_NOSUID | MsFlags::MS_NODEV, Some("mode=0755"))?;
    mount(Some("tmpfs"), "/tmp", Some("tmpfs"), MsFlags::MS_NOSUID | MsFlags::MS_NODEV, Some("mode=1777"))?;
    Ok(())
}

fn prepare(console: &Console) -> Result<rim_manifest::Manifest, String> {
    let text = fs::read_to_string(MANIFEST).map_err(|e| format!("{MANIFEST}: {e}"))?;
    let m = rim_manifest::parse(&text).map_err(|e| format!("{MANIFEST}: {e}"))?;

    let mut uevents = Vec::new();
    for entry in fs::read_dir("/sys/class/block").map_err(|e| format!("/sys/class/block: {e}"))? {
        let Ok(entry) = entry else { continue };
        let dev = entry.file_name().to_string_lossy().into_owned();
        if let Ok(ue) = fs::read_to_string(entry.path().join("uevent")) {
            uevents.push((dev, ue));
        }
    }
    let data = setup::find_partition(&uevents, "data").ok_or("раздел с PARTNAME=data не найден")?;
    mount(Some(data.as_str()), "/data", Some("ext4"), MsFlags::MS_NOSUID | MsFlags::MS_NODEV, None::<&str>)
        .map_err(|e| format!("mount {data} /data: {e}"))?;
    console.line(&format!("rim: /data = {data}"));

    for d in ["/data/ssh", "/data/log", "/data/root/.ssh"] {
        fs::create_dir_all(d).map_err(|e| format!("{d}: {e}"))?;
    }
    fs::set_permissions("/data/root/.ssh", fs::Permissions::from_mode(0o700)).map_err(|e| e.to_string())?;

    let host_key = "/data/ssh/host_ed25519";
    if fs::metadata(host_key).is_err() {
        console.line("rim: первая загрузка, создаю ключ хоста");
        let st = Command::new("/bin/dropbearkey")
            .args(["-t", "ed25519", "-f", host_key])
            .stdout(Stdio::null())
            .status()
            .map_err(|e| format!("dropbearkey: {e}"))?;
        if !st.success() {
            return Err(format!("dropbearkey: {st}"));
        }
    }
    let ak = "/data/root/.ssh/authorized_keys";
    fs::write(ak, setup::authorized_keys(&m.system.ssh_authorized_keys)).map_err(|e| format!("{ak}: {e}"))?;
    fs::set_permissions(ak, fs::Permissions::from_mode(0o600)).map_err(|e| e.to_string())?;

    sethostname(&m.system.hostname).map_err(|e| format!("sethostname: {e}"))?;
    let _ = Command::new("/sbin/ip").args(["link", "set", "lo", "up"]).status();
    Ok(m)
}

fn emergency(console: &Console, err: &str) -> ! {
    console.line(&format!("rim: ОШИБКА: {err}"));
    console.line("rim: аварийный shell на консоли (exit — перезапустить shell)");
    loop {
        let shell = (|| -> std::io::Result<std::process::ExitStatus> {
            let c = || OpenOptions::new().read(true).write(true).open("/dev/console");
            Command::new("/bin/sh").stdin(c()?).stdout(c()?).stderr(c()?).status()
        })();
        if shell.is_err() {
            std::thread::sleep(std::time::Duration::from_secs(5));
        }
        while let Ok(WaitStatus::Exited(..) | WaitStatus::Signaled(..)) = waitpid(Pid::from_raw(-1), Some(WaitPidFlag::WNOHANG)) {}
    }
}

fn supervise(m: rim_manifest::Manifest, console: Arc<Console>) -> ! {
    let mut mask = SigSet::empty();
    for s in [Signal::SIGCHLD, Signal::SIGTERM, Signal::SIGUSR1, Signal::SIGUSR2, Signal::SIGINT] {
        mask.add(s);
    }
    if let Err(e) = sigprocmask(SigmaskHow::SIG_BLOCK, Some(&mask), None) {
        emergency(&console, &format!("sigprocmask: {e}"));
    }
    let sfd = match SignalFd::with_flags(&mask, SfdFlags::SFD_NONBLOCK | SfdFlags::SFD_CLOEXEC) {
        Ok(s) => s,
        Err(e) => emergency(&console, &format!("signalfd: {e}")),
    };

    let start = Instant::now();
    let now = || start.elapsed().as_secs();
    let mut sup = Supervisor::new(m.service.iter().map(|(n, s)| (n.clone(), s.restart)));
    let mut queue = vec![Event::Boot { now: now() }];

    loop {
        while let Some(ev) = queue.pop() {
            for action in sup.step(ev) {
                match action {
                    Action::Spawn { name } => queue.push(spawn(&m, &name, &console, now())),
                    Action::Signal { pid, sig } => {
                        let s = if sig == Sig::Term { Signal::SIGTERM } else { Signal::SIGKILL };
                        let _ = kill(Pid::from_raw(pid), s);
                    }
                    Action::Log { line } => console.line(&format!("rim: {line}")),
                    Action::Ready => console.line("rim: ready"),
                    Action::Finish { kind } => finish(kind, &console),
                }
            }
        }

        let mut fds = [PollFd::new(sfd.as_fd(), PollFlags::POLLIN)];
        let _ = poll(&mut fds, PollTimeout::from(1000u16));
        while let Ok(Some(info)) = sfd.read_signal() {
            match Signal::try_from(info.ssi_signo as i32) {
                Ok(Signal::SIGCHLD) => loop {
                    match waitpid(Pid::from_raw(-1), Some(WaitPidFlag::WNOHANG)) {
                        Ok(WaitStatus::Exited(pid, code)) => queue.push(Event::Exited { pid: pid.as_raw(), status: code, now: now() }),
                        Ok(WaitStatus::Signaled(pid, sig, _)) => queue.push(Event::Exited { pid: pid.as_raw(), status: 128 + sig as i32, now: now() }),
                        Ok(WaitStatus::StillAlive) | Err(_) => break,
                        Ok(_) => {}
                    }
                },
                Ok(Signal::SIGUSR2) => queue.push(Event::ShutdownRequested { kind: ShutdownKind::Poweroff, now: now() }),
                Ok(Signal::SIGUSR1) => queue.push(Event::ShutdownRequested { kind: ShutdownKind::Halt, now: now() }),
                Ok(Signal::SIGTERM | Signal::SIGINT) => queue.push(Event::ShutdownRequested { kind: ShutdownKind::Reboot, now: now() }),
                _ => {}
            }
        }
        queue.insert(0, Event::Tick { now: now() });
    }
}

fn spawn(m: &rim_manifest::Manifest, name: &str, console: &Arc<Console>, now: u64) -> Event {
    let Some(svc) = m.service.get(name) else {
        return Event::SpawnFailed { name: name.into(), now };
    };
    let mut cmd = Command::new(&svc.exec[0]);
    cmd.args(&svc.exec[1..])
        .env_clear()
        .env("PATH", "/bin:/sbin")
        .env("HOME", "/data/root")
        .stdin(Stdio::null())
        .stdout(Stdio::piped())
        .stderr(Stdio::piped());
    // SAFETY: между fork и exec вызываем только async-signal-safe sigprocmask и setsid.
    unsafe {
        cmd.pre_exec(|| {
            sigprocmask(SigmaskHow::SIG_SETMASK, Some(&SigSet::empty()), None)?;
            setsid()?;
            Ok(())
        });
    }
    match cmd.spawn() {
        Ok(mut child) => {
            let log = OpenOptions::new().create(true).append(true).open(format!("/data/log/{name}.log")).ok();
            let log = Arc::new(Mutex::new(log));
            if let Some(out) = child.stdout.take() {
                pump(out, name, console.clone(), log.clone());
            }
            if let Some(err) = child.stderr.take() {
                pump(err, name, console.clone(), log);
            }
            Event::Spawned { name: name.into(), pid: child.id() as i32, now }
        }
        Err(e) => {
            console.line(&format!("rim: [{name}] {}: {e}", svc.exec[0]));
            Event::SpawnFailed { name: name.into(), now }
        }
    }
}

fn pump(src: impl Read + Send + 'static, name: &str, console: Arc<Console>, log: Arc<Mutex<Option<File>>>) {
    let name = name.to_string();
    std::thread::spawn(move || {
        for line in BufReader::new(src).lines().map_while(Result::ok) {
            console.line(&format!("[{name}] {line}"));
            if let Ok(mut guard) = log.lock() {
                if let Some(f) = guard.as_mut() {
                    let _ = writeln!(f, "{line}");
                }
            }
        }
    });
}

fn finish(kind: ShutdownKind, console: &Console) -> ! {
    console.line("rim: выключение");
    sync();
    let _ = umount("/data");
    sync();
    let mode = match kind {
        ShutdownKind::Poweroff => RebootMode::RB_POWER_OFF,
        ShutdownKind::Reboot => RebootMode::RB_AUTOBOOT,
        ShutdownKind::Halt => RebootMode::RB_HALT_SYSTEM,
    };
    let _ = reboot(mode);
    loop {
        std::thread::sleep(std::time::Duration::from_secs(60));
    }
}
```

```rust
//! GUID'ы выводятся из манифеста, а не из генератора случайных чисел: один манифест — один образ.

use sha2::{Digest, Sha256};

pub type Guid = [u8; 16];

pub fn derive(seed: &[u8], label: &str) -> Guid {
    let mut h = Sha256::new();
    h.update(seed);
    h.update([0u8]);
    h.update(label.as_bytes());
    let d = h.finalize();
    let mut g: Guid = d[..16].try_into().expect("sha256 длиннее 16 байт");
    g[6] = (g[6] & 0x0f) | 0x40;
    g[8] = (g[8] & 0x3f) | 0x80;
    g
}

pub fn fat_serial(seed: &[u8], label: &str) -> u32 {
    let g = derive(seed, label);
    u32::from_be_bytes([g[0], g[1], g[2], g[3]])
}

pub fn to_string(g: &Guid) -> String {
    let h: String = g.iter().map(|b| format!("{b:02x}")).collect();
    format!("{}-{}-{}-{}-{}", &h[0..8], &h[8..12], &h[12..16], &h[16..20], &h[20..32])
}

/// Разбор строки GUID. Только для констант в коде, поэтому паника на мусоре допустима.
pub fn parse(s: &str) -> Guid {
    let hex: String = s.chars().filter(|c| *c != '-').collect();
    assert_eq!(hex.len(), 32, "GUID {s}");
    let mut g = [0u8; 16];
    for (i, b) in g.iter_mut().enumerate() {
        *b = u8::from_str_radix(&hex[2 * i..2 * i + 2], 16).expect("hex в GUID");
    }
    g
}
```

```rust
//! Разметка диска: esp, root-A, root-B, data — выровнено по 1 MiB.

use crate::gpt::{ESP_TYPE, LINUX_FS_TYPE, ROOT_ARM64_TYPE, SECTOR};
use crate::ids::{self, Guid};
use rim_manifest::Disk;

pub const ALIGN: u64 = 2048;

#[derive(Debug, Clone, PartialEq)]
pub struct Part {
    pub label: &'static str,
    pub type_guid: Guid,
    pub first_lba: u64,
    pub last_lba: u64,
}

pub fn plan(disk: &Disk) -> (Vec<Part>, u64) {
    let spec = [
        ("esp", ESP_TYPE, disk.esp.0),
        ("root-A", ROOT_ARM64_TYPE, disk.root.0),
        ("root-B", ROOT_ARM64_TYPE, disk.root.0),
        ("data", LINUX_FS_TYPE, disk.data.0),
    ];
    let mut next = ALIGN;
    let mut parts = Vec::new();
    for (label, ty, bytes) in spec {
        let sectors = bytes / SECTOR;
        parts.push(Part { label, type_guid: ids::parse(ty), first_lba: next, last_lba: next + sectors - 1 });
        next += sectors.div_ceil(ALIGN) * ALIGN;
    }
    let total = parts.last().expect("4 раздела").last_lba + 1 + ALIGN;
    (parts, total)
}
```

```rust
//! Protective MBR + первичная и резервная GPT. Только байты, без файлов.

use crate::ids::Guid;

pub const SECTOR: u64 = 512;
pub const ESP_TYPE: &str = "c12a7328-f81f-11d2-ba4b-00a0c93ec93b";
pub const ROOT_ARM64_TYPE: &str = "b921b045-1df0-41c3-af44-4c6f280d3fae";
pub const LINUX_FS_TYPE: &str = "0fc63daf-8483-4772-8e79-3d69d8477de4";

const ENTRIES: usize = 128;
const ENTRY_SIZE: usize = 128;
const ENTRIES_BYTES: usize = ENTRIES * ENTRY_SIZE; // 16384 = 32 сектора

#[derive(Debug, Clone)]
pub struct PartEntry {
    pub type_guid: Guid,
    pub guid: Guid,
    pub first_lba: u64,
    pub last_lba: u64,
    pub name: String,
}

/// GUID в GPT хранится «смешанно»: первые три поля little-endian.
fn on_disk(g: &Guid) -> [u8; 16] {
    let mut o = *g;
    o[0..4].reverse();
    o[4..6].reverse();
    o[6..8].reverse();
    o
}

fn entries(parts: &[PartEntry]) -> Vec<u8> {
    let mut buf = vec![0u8; ENTRIES_BYTES];
    for (i, p) in parts.iter().enumerate() {
        let e = &mut buf[i * ENTRY_SIZE..(i + 1) * ENTRY_SIZE];
        e[0..16].copy_from_slice(&on_disk(&p.type_guid));
        e[16..32].copy_from_slice(&on_disk(&p.guid));
        e[32..40].copy_from_slice(&p.first_lba.to_le_bytes());
        e[40..48].copy_from_slice(&p.last_lba.to_le_bytes());
        for (j, u) in p.name.encode_utf16().take(36).enumerate() {
            e[56 + 2 * j..58 + 2 * j].copy_from_slice(&u.to_le_bytes());
        }
    }
    buf
}

fn header(my: u64, alt: u64, entries_lba: u64, total: u64, disk_guid: &Guid, entries_crc: u32) -> [u8; 512] {
    let mut h = [0u8; 512];
    h[0..8].copy_from_slice(b"EFI PART");
    h[8..12].copy_from_slice(&0x0001_0000u32.to_le_bytes());
    h[12..16].copy_from_slice(&92u32.to_le_bytes());
    h[24..32].copy_from_slice(&my.to_le_bytes());
    h[32..40].copy_from_slice(&alt.to_le_bytes());
    h[40..48].copy_from_slice(&34u64.to_le_bytes());
    h[48..56].copy_from_slice(&(total - 34).to_le_bytes());
    h[56..72].copy_from_slice(&on_disk(disk_guid));
    h[72..80].copy_from_slice(&entries_lba.to_le_bytes());
    h[80..84].copy_from_slice(&(ENTRIES as u32).to_le_bytes());
    h[84..88].copy_from_slice(&(ENTRY_SIZE as u32).to_le_bytes());
    h[88..92].copy_from_slice(&entries_crc.to_le_bytes());
    let crc = crc32fast::hash(&h[..92]);
    h[16..20].copy_from_slice(&crc.to_le_bytes());
    h
}

pub fn build(total: u64, disk_guid: Guid, parts: &[PartEntry]) -> (Vec<u8>, Vec<u8>) {
    let ents = entries(parts);
    let ents_crc = crc32fast::hash(&ents);
    let last = total - 1;

    let mut head = vec![0u8; 34 * SECTOR as usize];
    let mbr = &mut head[446..462];
    mbr[0..8].copy_from_slice(&[0x00, 0x00, 0x02, 0x00, 0xEE, 0xFF, 0xFF, 0xFF]);
    mbr[8..12].copy_from_slice(&1u32.to_le_bytes());
    mbr[12..16].copy_from_slice(&((total - 1).min(u32::MAX as u64) as u32).to_le_bytes());
    head[510] = 0x55;
    head[511] = 0xAA;
    head[512..1024].copy_from_slice(&header(1, last, 2, total, &disk_guid, ents_crc));
    head[1024..1024 + ENTRIES_BYTES].copy_from_slice(&ents);

    let mut tail = vec![0u8; 33 * SECTOR as usize];
    tail[..ENTRIES_BYTES].copy_from_slice(&ents);
    tail[ENTRIES_BYTES..].copy_from_slice(&header(last, 1, last - 32, total, &disk_guid, ents_crc));
    (head, tail)
}
```

```rust
pub fn cache_key(files: &[(String, Vec<u8>)], toolchain_id: &str) -> String {
    let mut sorted: Vec<_> = files.iter().collect();
    sorted.sort_by(|a, b| a.0.cmp(&b.0));
    let mut h = Sha256::new();
    h.update(b"rim-cache-v1\0");
    h.update(toolchain_id.as_bytes());
    h.update([0u8]);
    for (path, data) in sorted {
        h.update((path.len() as u64).to_le_bytes());
        h.update(path.as_bytes());
        h.update((data.len() as u64).to_le_bytes());
        h.update(data);
    }
    h.finalize()[..16].iter().map(|b| format!("{b:02x}")).collect()
}
```

```rust
//! Что лежит в корне помимо пакетов. Чистый план: материализует его image.rs.

#[derive(Debug, Clone, PartialEq)]
pub enum Entry {
    Dir(String),
    File { path: String, data: Vec<u8>, mode: u32 },
    Symlink { path: String, target: String },
}

impl Entry {
    pub fn path(&self) -> &str {
        match self {
            Entry::Dir(p) => p,
            Entry::File { path, .. } | Entry::Symlink { path, .. } => path,
        }
    }
}

pub fn plan(manifest: &[u8], udhcpc_script: &[u8]) -> Vec<Entry> {
    let mut v: Vec<Entry> = [
        "bin", "sbin", "etc", "etc/rim", "proc", "sys", "dev", "run", "tmp", "data", "var",
    ]
    .iter()
    .map(|d| Entry::Dir(d.to_string()))
    .collect();
    let file = |p: &str, d: &[u8], mode| Entry::File { path: p.into(), data: d.to_vec(), mode };
    let link = |p: &str, t: &str| Entry::Symlink { path: p.into(), target: t.into() };
    v.extend([
        file("etc/passwd", b"root:x:0:0:root:/data/root:/bin/sh\n", 0o644),
        file("etc/group", b"root:x:0:\n", 0o644),
        file("etc/shells", b"/bin/sh\n", 0o644),
        file("etc/rim/system.toml", manifest, 0o644),
        file("etc/rim/udhcpc.script", udhcpc_script, 0o755),
        link("etc/resolv.conf", "/run/resolv.conf"),
        link("var/run", "/run"),
    ]);
    v
}
```

```rust
//! Пакет = recipe.toml + build.sh. Результат кэшируется по хэшу рецепта и тулчейна.

use crate::recipe::{Kind, Recipe, cache_key};
use crate::sh;
use sha2::{Digest, Sha256};
use std::fs;
use std::path::{Path, PathBuf};
use std::process::Command;

fn read_dir_files(dir: &Path) -> Result<Vec<(String, Vec<u8>)>, String> {
    let mut out = Vec::new();
    let mut stack = vec![dir.to_path_buf()];
    while let Some(d) = stack.pop() {
        for e in fs::read_dir(&d).map_err(|e| format!("{}: {e}", d.display()))? {
            let p = e.map_err(|e| e.to_string())?.path();
            if p.is_dir() {
                stack.push(p);
            } else {
                let rel = p.strip_prefix(dir).expect("внутри dir").to_string_lossy().into_owned();
                out.push((rel, fs::read(&p).map_err(|e| format!("{}: {e}", p.display()))?));
            }
        }
    }
    Ok(out)
}

fn sha256_file(p: &Path) -> Result<String, String> {
    let data = fs::read(p).map_err(|e| format!("{}: {e}", p.display()))?;
    Ok(Sha256::digest(&data).iter().map(|b| format!("{b:02x}")).collect())
}

fn fetch(root: &Path, r: &Recipe) -> Result<PathBuf, String> {
    let dir = root.join("out/cache/src");
    fs::create_dir_all(&dir).map_err(|e| e.to_string())?;
    let dst = dir.join(&r.sha256);
    if dst.exists() {
        return Ok(dst);
    }
    let tmp = dir.join(format!("{}.part", r.sha256));
    sh::run(Command::new("curl").args(["-fsSL", "-o"]).arg(&tmp).arg(&r.url))?;
    let got = sha256_file(&tmp)?;
    if got != r.sha256 {
        let _ = fs::remove_file(&tmp);
        return Err(format!("{}: sha256 {got}, ожидался {}", r.url, r.sha256));
    }
    fs::rename(&tmp, &dst).map_err(|e| e.to_string())?;
    Ok(dst)
}

pub fn ensure(root: &Path, name: &str, toolchain_id: &str) -> Result<(PathBuf, Kind), String> {
    let rdir = root.join("pkgs").join(name);
    let text = fs::read_to_string(rdir.join("recipe.toml"))
        .map_err(|e| format!("пакет {name}: нет pkgs/{name}/recipe.toml ({e})"))?;
    let recipe = Recipe::parse(&text).map_err(|e| format!("pkgs/{name}/recipe.toml: {e}"))?;
    let key = cache_key(&read_dir_files(&rdir)?, toolchain_id);
    let out = root.join(format!("out/cache/{key}-{name}"));
    if out.exists() {
        return Ok((out, recipe.kind));
    }

    let src_archive = fetch(root, &recipe)?;
    let work = root.join(format!("out/work/src-{name}"));
    let tmp_out = root.join(format!("out/cache/{key}-{name}.tmp"));
    for d in [&work, &tmp_out] {
        let _ = fs::remove_dir_all(d);
        fs::create_dir_all(d).map_err(|e| format!("{}: {e}", d.display()))?;
    }
    sh::run(Command::new("tar").arg("xf").arg(&src_archive).arg("-C").arg(&work).arg("--strip-components=1"))?;
    let jobs = std::thread::available_parallelism().map(|n| n.get()).unwrap_or(4);
    sh::run(
        Command::new("sh")
            .arg(rdir.join("build.sh"))
            .env("SRC", &work)
            .env("OUT", &tmp_out)
            .env("RECIPE", &rdir)
            .env("JOBS", jobs.to_string()),
    )
    .map_err(|e| format!("сборка пакета {name}: {e}"))?;
    fs::rename(&tmp_out, &out).map_err(|e| e.to_string())?;
    Ok((out, recipe.kind))
}
```

```rust
//! Манифест → rim.img: корень (erofs), UKI, ESP, data, GPT. Без loop-устройств.

use crate::gpt::{self, PartEntry, SECTOR};
use crate::ids;
use crate::layout;
use crate::pkg;
use crate::recipe::Kind;
use crate::rootfs::{self, Entry};
use crate::sh;
use sha2::{Digest, Sha256};
use std::fs::{self, File};
use std::io::{Seek, SeekFrom, Write};
use std::os::unix::fs::{PermissionsExt, symlink};
use std::path::{Path, PathBuf};
use std::process::Command;

const EPOCH: &str = "1767225600";
const STUB: &str = "/usr/lib/systemd/boot/efi/linuxaa64.efi.stub";

pub fn build(root: &Path, manifest_path: &Path, target: &str, out: &Path) -> Result<String, String> {
    let bytes = fs::read(manifest_path).map_err(|e| format!("{}: {e}", manifest_path.display()))?;
    let text = String::from_utf8(bytes.clone()).map_err(|_| "манифест не UTF-8".to_string())?;
    let m = rim_manifest::parse(&text).map_err(|e| format!("{}: {e}", manifest_path.display()))?;
    let t = m.target.get(target).ok_or_else(|| format!("нет [target.{target}]"))?;
    let tc = std::env::var("RIM_TOOLCHAIN_ID").unwrap_or_else(|_| "dev".into());

    let mut trees = Vec::new();
    for name in &m.system.packages {
        let (dir, kind) = pkg::ensure(root, name, &tc)?;
        if kind != Kind::Rootfs {
            return Err(format!("пакет {name}: kind = {kind:?}, в system.packages допустим только rootfs"));
        }
        trees.push(dir);
    }
    let (kdir, kkind) = pkg::ensure(root, &t.kernel, &tc)?;
    if kkind != Kind::Kernel {
        return Err(format!("target.{target}.kernel = {}: пакет не kind = \"kernel\"", t.kernel));
    }

    let work = root.join("out/work/image");
    let _ = fs::remove_dir_all(&work);
    fs::create_dir_all(&work).map_err(|e| e.to_string())?;

    // 1. Корень
    let rootdir = work.join("rootfs");
    for tree in &trees {
        fs::create_dir_all(&rootdir).map_err(|e| e.to_string())?;
        sh::run(Command::new("cp").arg("-a").arg(format!("{}/.", tree.display())).arg(&rootdir))?;
    }
    let script = fs::read(root.join("files/udhcpc.script")).map_err(|e| format!("files/udhcpc.script: {e}"))?;
    materialize(&rootdir, &rootfs::plan(&bytes, &script))?;
    let init_bin = PathBuf::from(std::env::var("RIM_INIT_BIN").map_err(|_| "RIM_INIT_BIN не задан (запускайте через ./rim)")?);
    fs::copy(&init_bin, rootdir.join("sbin/init")).map_err(|e| format!("{}: {e}", init_bin.display()))?;
    fs::set_permissions(rootdir.join("sbin/init"), fs::Permissions::from_mode(0o755)).map_err(|e| e.to_string())?;
    sh::run(Command::new("find").arg(&rootdir).args(["-exec", "touch", "-h", "-d", &format!("@{EPOCH}"), "{}", "+"]))?;

    let root_uuid = ids::to_string(&ids::derive(&bytes, "fs:root"));
    let root_img = work.join("root.erofs");
    sh::run(
        Command::new("mkfs.erofs")
            .arg(format!("-T{EPOCH}"))
            .arg(format!("-U{root_uuid}"))
            .arg("--all-root")
            .arg("-Enoinline_data")
            .arg(&root_img)
            .arg(&rootdir),
    )?;

    // 2. Разметка: нужен PARTUUID root-A для cmdline
    let (parts, total) = layout::plan(&t.disk);
    let part_guid = |label: &str| ids::derive(&bytes, &format!("part:{label}"));
    let cmdline = format!(
        "root=PARTUUID={} rootfstype=erofs ro rootwait console=ttyAMA0 console=tty0 panic=10",
        ids::to_string(&part_guid("root-A"))
    );

    // 3. UKI
    let uki = work.join("rim-A.efi");
    sh::run(
        Command::new("ukify")
            .arg("build")
            .arg(format!("--linux={}", kdir.join("boot/Image").display()))
            .arg(format!("--stub={STUB}"))
            .arg(format!("--cmdline={cmdline}"))
            .arg("--os-release=NAME=rim\nID=rim\nPRETTY_NAME=rim v1\n")
            .arg(format!("--output={}", uki.display())),
    )?;

    // 4. ESP
    let esp_img = work.join("esp.img");
    let esp_sectors = t.disk.esp.0 / SECTOR;
    File::create(&esp_img).and_then(|f| f.set_len(t.disk.esp.0)).map_err(|e| e.to_string())?;
    let mt = |args: &[&str]| -> Result<(), String> {
        sh::run(Command::new(args[0]).args(&args[1..]).env("SOURCE_DATE_EPOCH", EPOCH).env("MTOOLS_SKIP_CHECK", "1"))
    };
    let esp = esp_img.to_string_lossy().into_owned();
    let serial = format!("{:08x}", ids::fat_serial(&bytes, "fs:esp"));
    mt(&["mformat", "-i", &esp, "-F", "-v", "ESP", "-N", &serial, "-T", &esp_sectors.to_string(), "-h", "64", "-s", "32", "::"])?;
    mt(&["mmd", "-i", &esp, "::/EFI", "::/EFI/BOOT", "::/EFI/rim"])?;
    let uki_s = uki.to_string_lossy().into_owned();
    sh::run(Command::new("touch").args(["-d", &format!("@{EPOCH}"), &uki_s]))?;
    mt(&["mcopy", "-m", "-i", &esp, &uki_s, "::/EFI/BOOT/BOOTAA64.EFI"])?;
    mt(&["mcopy", "-m", "-i", &esp, &uki_s, "::/EFI/rim/rim-A.efi"])?;

    // 5. data (пустая ext4)
    let data_img = work.join("data.img");
    let empty = work.join("data-empty");
    fs::create_dir_all(&empty).map_err(|e| e.to_string())?;
    let data_uuid = ids::to_string(&ids::derive(&bytes, "fs:data"));
    let seed = ids::to_string(&ids::derive(&bytes, "fs:data-hash"));
    sh::run(
        Command::new("mke2fs")
            .args(["-q", "-F", "-t", "ext4", "-L", "data", "-U", &data_uuid])
            .arg("-E")
            .arg(format!("hash_seed={seed},root_owner=0:0"))
            .arg("-d")
            .arg(&empty)
            .arg(&data_img)
            .arg(format!("{}k", t.disk.data.0 / 1024))
            .env("E2FSPROGS_FAKE_TIME", EPOCH),
    )?;

    // 6. Склейка
    let entries: Vec<PartEntry> = parts
        .iter()
        .map(|p| PartEntry { type_guid: p.type_guid, guid: part_guid(p.label), first_lba: p.first_lba, last_lba: p.last_lba, name: p.label.to_string() })
        .collect();
    let (head, tail) = gpt::build(total, ids::derive(&bytes, "disk"), &entries);
    if let Some(dir) = out.parent() {
        fs::create_dir_all(dir).map_err(|e| e.to_string())?;
    }
    let tmp = out.with_extension("img.tmp");
    let mut f = File::create(&tmp).map_err(|e| format!("{}: {e}", tmp.display()))?;
    f.set_len(total * SECTOR).map_err(|e| e.to_string())?;
    let mut put = |lba: u64, data: &[u8]| -> Result<(), String> {
        f.seek(SeekFrom::Start(lba * SECTOR)).and_then(|_| f.write_all(data)).map_err(|e| e.to_string())
    };
    put(0, &head)?;
    put(total - 33, &tail)?;
    for (p, img) in parts.iter().zip([Some(&esp_img), Some(&root_img), None, Some(&data_img)]) {
        let Some(img) = img else { continue };
        let data = fs::read(img).map_err(|e| format!("{}: {e}", img.display()))?;
        let cap = (p.last_lba - p.first_lba + 1) * SECTOR;
        if data.len() as u64 > cap {
            return Err(format!("{}: {} байт не влезает в раздел {} ({} байт)", img.display(), data.len(), p.label, cap));
        }
        put(p.first_lba, &data)?;
    }
    drop(f);
    fs::rename(&tmp, out).map_err(|e| e.to_string())?;

    let digest: String = Sha256::digest(fs::read(out).map_err(|e| e.to_string())?).iter().map(|b| format!("{b:02x}")).collect();
    Ok(digest)
}

fn materialize(rootdir: &Path, plan: &[Entry]) -> Result<(), String> {
    for e in plan {
        let p = rootdir.join(e.path());
        match e {
            Entry::Dir(_) => fs::create_dir_all(&p).map_err(|er| format!("{}: {er}", p.display()))?,
            Entry::File { data, mode, .. } => {
                fs::write(&p, data).map_err(|er| format!("{}: {er}", p.display()))?;
                fs::set_permissions(&p, fs::Permissions::from_mode(*mode)).map_err(|er| er.to_string())?;
            }
            Entry::Symlink { target, .. } => {
                let _ = fs::remove_file(&p);
                symlink(target, &p).map_err(|er| format!("{}: {er}", p.display()))?;
            }
        }
    }
    Ok(())
}
```

```bash
# Грузит тестовый образ в QEMU (HVF) и проверяет систему снаружи, как пользователь VPS.
set -uo pipefail
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
"$ROOT/rim" build --manifest tests/rim.test.toml --out out/rim-test.img >/dev/null || { echo "FAIL сборка"; exit 1; }

WORK="$(mktemp -d)"
trap 'kill "$QPID" 2>/dev/null; rm -rf "$WORK"' EXIT

truncate -s 2G "$WORK/disk.img"         # диск VPS больше образа: резервная GPT не в конце
KEY="$WORK/key"; cp "$ROOT/tests/keys/id_ed25519" "$KEY"; chmod 600 "$KEY"
LOG="$WORK/serial.log"; : > "$LOG"
FW="$(brew --prefix qemu)/share/qemu/edk2-aarch64-code.fd"
PORT=2222
FAILED=0

qemu-system-aarch64 -M virt -accel hvf -cpu host -smp 2 -m 512M -bios "$FW" \
  -drive file="$WORK/disk.img",if=virtio,format=raw \
  -device virtio-net-pci,netdev=n0 -netdev user,id=n0,hostfwd=tcp:127.0.0.1:$PORT-:22 \
  -device virtio-rng-pci -display none -serial file:"$LOG" &
QPID=$!

# STRICT=accept-new при первом входе запоминает ключ хоста; STRICT=yes потом требует тот же ключ.
STRICT=accept-new
rsh() {
  ssh -i "$KEY" -p $PORT -o ConnectTimeout=5 -o BatchMode=yes \
    -o UserKnownHostsFile="$WORK/known_hosts" -o StrictHostKeyChecking=$STRICT root@127.0.0.1 "$@"
}
check() { local name="$1"; shift; if "$@" >/dev/null 2>&1; then echo "ok   $name"; else echo "FAIL $name"; FAILED=1; fi; }
ready_count() { grep -c '^rim: ready' "$LOG" || true; }
wait_ready() { for _ in $(seq 1 "$2"); do [ "$(ready_count)" -ge "$1" ] && return 0; sleep 1; done; return 1; }
wait_ssh() { for _ in $(seq 1 20); do rsh true && return 0; sleep 1; done; return 1; }
root_is_readonly() { rsh 'touch /x 2>&1' | grep -q 'Read-only'; }
hostname_ok() { [ "$(rsh hostname)" = rim-test ]; }
no_suid() { [ -z "$(rsh 'find / -xdev -perm -4000')" ]; }
password_refused() {
  ! ssh -p $PORT -o BatchMode=yes -o PreferredAuthentications=password -o PubkeyAuthentication=no \
      -o UserKnownHostsFile="$WORK/known_hosts" root@127.0.0.1 true
}
kill_sshd_listener() {
  rsh 'for p in $(pidof dropbear); do [ "$(cut -d" " -f4 /proc/$p/stat)" = 1 ] && kill $p; done; true'
}
fingerprint() { rsh 'dropbearkey -y -f /data/ssh/host_ed25519' | grep Fingerprint; }
qemu_exits() { for _ in $(seq 1 20); do kill -0 "$QPID" 2>/dev/null || return 0; sleep 1; done; return 1; }

check "rim: ready за 30 с"                  wait_ready 1 30
check "ssh по ключу"                        wait_ssh
check "корень только для чтения"            root_is_readonly
check "hostname из манифеста"               hostname_ok
check "SUID-бинарников нет"                 no_suid
check "пароль не принимается"               password_refused

FP1="$(fingerprint)"
kill_sshd_listener >/dev/null 2>&1
sleep 3
check "упавший sshd перезапущен"            wait_ssh

rsh reboot >/dev/null 2>&1
STRICT=yes                                  # дальше ssh требует прежний ключ хоста
check "после reboot снова ready"            wait_ready 2 60
check "ssh после reboot с прежним ключом"   wait_ssh
FP2="$(fingerprint)"
check "отпечаток ключа хоста не изменился"  test -n "$FP1" -a "$FP1" = "$FP2"

rsh poweroff >/dev/null 2>&1
check "poweroff завершает QEMU"             qemu_exits

if [ $FAILED -ne 0 ]; then
  echo "--- serial.log (хвост) ---"; tail -40 "$LOG"
fi
exit $FAILED
```
