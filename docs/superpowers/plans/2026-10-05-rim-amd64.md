# rim: x86_64 для Firecracker — план

> Исполнение: superpowers:executing-plans (натив). RED → GREEN → коммит.

**Spec:** docs/superpowers/specs/2026-10-05-rim-amd64-design.md
**Ветка:** feat/amd64

## Global Constraints
- arm64 не регрессирует: `test-boot.sh` 14/14, `test-boot-fc.sh` 13/13, `cargo test --workspace` зелёный.
- x86 fc детерминирован (cmp `.img`, `.vmlinux`, `.firecracker.json`).

## Review Focus
1. `./rim` без `--arch` ведёт себя как раньше (тот же образ тулчейна, тот же CARGO_TARGET_DIR).
2. Манифест x86_64 собран arm64-тулчейном → понятная ошибка, а не arm64-ядро в x86-образе.
3. `rim.poweroff=reboot` отсутствует → poweroff прежний (arm64 PSCI).
4. Ключ кэша пакетов различает платформы (toolchain id).
5. Неизвестное значение `arch` → ошибка парсинга с именем поля.

### Task 1: Манифест `arch`
RED: `arch_defaults_to_aarch64`, `x86_64_direct_ok`, `x86_64_uki_rejected`, `unknown_arch_rejected`.
GREEN: `enum Arch { Aarch64, X86_64 }` (`#[serde(rename_all = "snake_case")]` → "aarch64"/"x86_64"), `Target.arch` default.

### Task 2: layout/gpt/bootargs по arch
RED: `layout::tests::x86_root_type`, `bootargs::tests::cmdline_direct_x86`, `firecracker_json` без изменений.
GREEN: `ROOT_X86_64_TYPE`, `plan(disk, arch)`, `cmdline(boot, arch, net, uuid)`.

### Task 3: init `poweroff_as_reboot`
RED: `poweroff_as_reboot_only_with_flag` (точное слово, не подстрока `rim.poweroff=rebootX`).
GREEN: функция + `finish` читает /proc/cmdline.

### Task 4: image.rs + main: сверка arch, имя ядра по arch
`kernel_file(arch)`: aarch64 → `boot/Image`, x86_64 → `boot/vmlinux`; выход `<stem>.Image` | `<stem>.vmlinux`.
Ошибка при `t.arch != host`.

### Task 5: Тулчейн и ядро x86
Обёртка `--arch`; CARGO_BUILD_TARGET из Dockerfile в обёртку; `build.sh` по `uname -m`; `x86_64.config`.
Проверка: `./rim --arch x86_64 pkg linux` проходит check-config; `./rim pkg linux` — тот же ключ кэша, что до работ.

### Task 6: Тест и детерминизм
`tests/rim.fc.test.toml` + `[target.fc-x86]`; `ARCH=x86_64 scripts/test-boot-fc.sh` (microvm, TCG, -no-reboot); cmp двух сборок; регрессия arm64.

### Task 7: Документация
`docs/firecracker.md` (x86: vmlinux, reboot=k, вложенная виртуализация), README.
